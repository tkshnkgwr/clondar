# Tauri v2 デスクトップウィジェット開発ガイドライン (AGENTS.md)

本プロジェクトにおける大賢者の開発指示書です。
最優先ルール（コミット禁止・テーブル整列等）は [[GEMINI.md]] を参照してください。

## 🎯 開発・品質ルール

- **技術解説方針（他言語経験に配慮）**:
  - ユーザーは **Rust、React、TypeScript などの固有言語仕様・専門用語（所有権、ライフタイム、トレイト、フック等）には不慣れ**です。
  - これらの難解な専門用語をそのまま多用せず、一般的・共通的なプログラミング概念（参照, インターフェース, モジュール, 関数など）に置き換えるか、直感的に理解できるよう分かりやすく補足・解説を添えること。
- **事前検証とドキュメント同期**:
  - 開発およびドキュメント更新の際は、必ず [`docs/ja/INSTRUCTIONS.md`](../docs/ja/INSTRUCTIONS.md) に記載されている「ドキュメント自動同期ルール」および「品質管理・検証プロセス」に厳格に従って検証・同期を行うこと。
- **コード規模とリファクタリング**:
  - 単一のソースファイル（`*.rs`, `*.jsx`, `*.js` 等）の行数が **1000行を超えた場合**、AIはモジュール分割やコンポーネント抽出によるリファクタリングを積極的に検討・提案すること。
