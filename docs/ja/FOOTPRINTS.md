# フットプリント記録 (FOOTPRINTS.md) - Clondar

[English Version](../en/FOOTPRINTS.md) | **日本語版**

このドキュメントでは、`Clondar Pro` (v2.0.0 Pure Rust / `egui + glow` 版) のバイナリサイズ、実機メモリ消費量比較、およびリリースビルド設定を記録しています。

---

## 1. 計測環境

- **OS**: Windows 11 64-bit
- **ツールチェイン**: Rust stable (`x86_64-pc-windows-msvc`), NSIS (`makensis`)
- **対象バイナリ**:
  - 実行バイナリ: `target/release/Clondar.exe`
  - インストーラー: `installer/Clondar_Pro_2.0.0_x64-setup.exe`

---

## 2. フットプリント実測値

### 2.1 バイナリ・パッケージサイズ (v2.0.0 実測)

| ビルド・成果物名称                       |          サイズ           | 備考                                                   |
| :--------------------------------------- | :-----------------------: | :----------------------------------------------------- |
| `Clondar.exe` (Release)                  | **4.89 MB** (5,125,120 B) | LTO・`opt-level = 'z'`・シンボルストリップ・アイコン済 |
| `Clondar_Pro_2.0.0_x64-setup.exe` (NSIS) | **2.59 MB** (2,714,117 B) | 日英対応 NSIS インストーラー (zlib 圧縮)               |

> **特記**: `egui + glow`（OpenGL 単体）へ一本化したことで、ランタイム依存の WebView2 等を含まずに単一バイナリ **4.89 MB**・インストーラー **2.59 MB** を実現しました（`wgpu` 試作版 `7.91 MB` 比で約 3 MB 削減）。

---

### 2.2 同時実機計測によるメモリ比較 (2026-11-16 16:38:13)

Windows 実機で旧 Tauri 版・`wgpu` 版・`glow` 版を比較計測した結果は以下の通りです：

| 版 / 構成                        | プロセス数 | 固有メモリ (Private) |  WorkingSet   | 累積 CPU 時間       |
| :------------------------------- | :--------: | :------------------: | :-----------: | :------------------ |
| **改良前 (`v1.4.1`, WebView2)**  |     7      |      207.51 MB       |   192.17 MB   | 34.30 s (約 100分)  |
| **Phase B (`v1.4.4`, 表示中)**   |     7      |      190.74 MB       |   364.81 MB   | 25.03 s (約 35分)   |
| **Phase C 試作 (`egui + wgpu`)** |     1      |      293.06 MB       |   349.54 MB   | 6.17 s (約 2分)     |
| **Phase C 採用 (`egui + glow`)** |   **1**    |     **68.45 MB**     | **115.76 MB** | **1.78 s** (約 2分) |

* **`wgpu` 版比**: **`293.06 MB` → `68.45 MB`**（**`-224.61 MB` / -76.6% 削減**）
* **Phase B 表示中比**: **`190.74 MB` → `68.45 MB`**（**`-122.29 MB` / -64.1% 削減**）
* **改良前 (`v1.4.1`) 比**: **`-139.06 MB`**（**-67.0% 削減**）
* **技術的要因**: `eframe 0.37.0` のデフォルト `wgpu` は Direct3D 12 / Vulkan / シェーダコンパイラ DLL（`igd12um64xel.dll`, `igvk64.dll`, `dxcompiler.dll` 等）を読み込み 200 MB 超を消費していました。`glow`（OpenGL 単体）指定によりこれらが完全に排除され、単一プロセスでの超軽量常駐を達成しています。

## 3. リリースビルド最適化設定 (`Cargo.toml`)

バイナリサイズと実行時フットプリントを最小限に抑えるため、ルート `Cargo.toml` に以下の最適化プロファイルを定義しています：

```toml
[profile.release]
opt-level = 'z'     # サイズ優先の最適化
lto = true          # Link-Time Optimization (LTO) の有効化
codegen-units = 1   # 単一コンパイル単位による最大化最適化
panic = 'abort'     # パニック展開テーブル削減
strip = true        # シンボル・デバッグ情報のストリップ
```
