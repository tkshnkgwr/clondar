# セキュリティポリシー (SECURITY.md) - Clondar

[English Version](../en/SECURITY.md) | **日本語版**

本ドキュメントは、`Clondar Pro` プロジェクトにおけるセキュリティ方針、設計上の安全性担保、および脆弱性報告ガイドラインを定義します。

---

## 1. セキュリティ設計方針

`Clondar Pro` (v2.0.0) は Pure Rust ネイティブアプリとして、以下の設計原則に基づいて安全な実行環境を維持します。

1. **単一プロセス ＆ ブラウザエンジン排除 (Zero WebView / JS Runtime)**:
   - v2.0.0 では WebView2 / Chromium や JavaScript エンジン、外部 Node.js 依存を完全に撤廃しました。これにより、Web ブラウザエンジンや JavaScript サンドボックス由来の攻撃対象領域（Attack Surface）が存在しません。
2. **Rust によるメモリ安全性**:
   - UI・設定パーサー・システムトレイ・祝日計算を含む全コードが Rust でコンパイルされており、コンパイル時の所有権・型検査によってバッファオーバーフローや不正メモリアクセスを構造的に防止しています。
3. **完全ローカル完結（オフライン保証）**:
   - アプリケーションは外部サーバーやネットワークへ一切通信を行いません。設定ファイル（`state.json`, `holidays.json`）は `%LOCALAPPDATA%\com.clondar.pro\` 配下にのみ保存され、不正な日付や書式に対しては Serde スキーマ検証および範囲チェックで保存前に遮断します。

## 3. 脆弱性の報告手順

`Clondar Pro` においてセキュリティ上の問題や脆弱性を発見された場合は、公開 Issue（GitHub Issues）ではなく、メンテナーへの直接連絡にてご報告ください。

ご報告の際は、迅速な調査・修正のため以下の情報をご提供ください：
1. 問題が発生したアプリケーションのバージョン、および実行環境（Windows ビルドバージョン、GPU ドライバ等）
2. 脆弱性の詳細な内容と再現手順（可能な場合は再現用データや設定ファイル）

報告を受領後、速やかに調査・再現確認を行い、修正パッチの適用とアップデートリリースを実施します。
