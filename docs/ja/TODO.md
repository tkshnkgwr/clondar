## 3. 今後の拡張提案 (Backlog)

### 🎨 UI・表示カスタマイズ
- [ ] **アプリ動作中の UI 表示言語の動的切り替え**
  - カレンダーの曜日や祝日名、設定ダイアログ内の各種テキストを、アプリ内の設定から「日本語 ⇄ 英語」へ動的に切り替えられるようにする多言語ローカライズ機能。
- [ ] **テーマカラーと透過度の詳細カスタマイズ**
  - 背景透過の度合い（ブラーの強度）をスライダーで細かく調整でき、テーマカラー（現在はブルーベース固定）を数種類から選べるようにするパーソナライズ設定機能。
- [ ] **コンパクト表示モード（ミニマルウィジェットモード）**
  - 時計のみ、またはカレンダーのみを極小サイズで画面端に常駐表示できるレイアウト切替機能。
- [ ] **カレンダー週の開始曜日（日曜日 / 月曜日）切り替え機能**
  - ビジネス利用や個人の好みに応じて、カレンダーの週始まりを「日曜日始まり」または「月曜日始まり」に切り替えられるオプション。
- [ ] **カレンダー週番号（Week Number / ISO 8601）の表示オプション**
  - カレンダー左端に年間を通した週番号（第何週目か）を表示するビジネス向けトグル設定。
- [ ] **マルチタイムゾーン（世界時計）サブ表示**
  - メイン時計の下部に、UTCや海外主要都市（ニューヨーク、ロンドン等）の時刻をコンパクトにサブ表示できる機能。

### ⚡ 利便性・システム連携
- [ ] **グローバルショートカット（ホットキー）による瞬時トグル**
  - キーボードの特定ショートカット（例: `Alt+Shift+C` 等）を押すことで、他の作業中でも瞬時にウィジェットの表示/非表示や最前面ピン留めを切り替えられる機能（Tauri の global-shortcut プラグイン等の導入）。
- [ ] **スタートアップ自動起動設定の UI 統合**
  - PC起動時にウィジェットを自動で起動させる「スタートアップ登録」オプションを、設定メニューやトレイメニューの UI から直接 ON/OFF 切り替えできる機能（Tauri の autostart プラグイン等の導入）。
- [ ] **作業集中ゴーストモード（マウスホバー時透過 / クリック透過）**
  - ウィジェット背後にあるウィンドウの文字を確認・操作したい場合に、マウスカーソル接近時に一時的に透明度を上げる、またはクリックを背面へ透過（Click-through）させるモード。

### 📅 スケジュール・データ連携
- [ ] **簡易スケジューラー（ToDo・予定管理）＆リマインダー通知**
  - カレンダーの日付セルをクリックすることで、ユーザーがその日の簡単なスケジュールや ToDo を登録・保存し、カレンダー上にインジケーター表示するとともに、指定時刻に Windows のトースト通知でリマインドする機能。
- [ ] **祝日定義ファイルのオンライン自動更新**
  - 祝日の法改正に自動で追随するため、起動時にGitHubなどの特定サーバーから最新の `holidays.json` をバックグラウンドで自動取得・更新する仕組み。
- [ ] **祝日・イベントデータのインポート/エクスポート (iCalendar / CSV / JSON)**
  - 外部カレンダーツール（GoogleカレンダーやOutlook等）とのデータ共有やバックアップを可能にする、iCal (.ics) / CSV / JSON 形式での入出力機能。
