# Clondar Pro ユーザーガイド

[English Version](../en/USER_GUIDE.md) | **日本語版**

Clondar Pro をご利用いただきありがとうございます。  
本ガイドでは、アプリケーションのインストール、基本操作、時計やカレンダーのカスタマイズ、および「祝日設定マネージャー」の使用方法について詳しく説明します。

---

## 1. インストールと起動

### 1.1 動作要件
- **対応OS**: Windows 10 / 11 (64bit)
- **依存環境**: Microsoft Edge WebView2 ランタイム  
  ※ 通常の Windows 環境には標準で導入されています。未導入の場合は、起動時に自動でインストールウィザードが表示されます。

### 1.2 インストール手順
1. 配布されたインストーラーファイル（`app_x.x.x_x64_ja-JP.msi` または `app-setup.exe`）をダブルクリックして起動します。
2. インストール時の言語（日本語 / English）を選択するダイアログが表示されたら、「日本語」を選択します。
3. 画面の指示に従ってインストール先を指定し、完了ボタンを押します。
4. インストール完了後、デスクトップのショートカットまたはスタートメニューから **Clondar** を起動します。

## 2. 画面構成と基本操作

Clondar Pro は、デスクトップの壁紙に溶け込む透過型のウィジェットです。

- **ドラッグによる移動**:  
  ウィジェット内の任意の場所（時計やカレンダーの文字が無い背景部分など）をドラッグすることで、画面上の好きな位置へ自由に移動できます。
- **最前面表示（ピン留め）**:  
  タイトルバー右上のピンアイコン（📌）をクリックすることで、他のアプリケーションを最大化していても、常にウィジェットを一番手前に表示し続ける（Always on Top）ことができます。もう一度クリックすると解除されます。
- **背景透過切替**:  
  太陽アイコン（☀️）をクリックすることで、壁紙に溶け込む透過モード（グラスモーフィズム）のON/OFFを切り替えることができます。
- **ヘルプ＆アプリ情報（❓）**:  
  タイトルバー右上のヘルプアイコン（❓）をクリックすると、アプリの概要説明、現在のバージョン情報、および各種操作ガイドをまとめたモーダル画面が表示されます。
- **表示・非表示の切替**:  
  ウィジェット右上の「❌」ボタンをクリックするか、キーボードの `Esc` キーを押すと画面が消えます（モーダルが開いている場合はモーダルのみを閉じます）。これは一時的に非表示（常駐状態）にしているだけで、後述するシステムトレイからいつでも再表示できます。

## 3. 時計・カレンダー機能の使い方

### 3.1 時計モードの切替
時計エリア上部のタブボタン（`DIGITAL` / `ANALOG`）をクリックすることで、表示形式を変更できます。
- **デジタル時計**: `Impact` 調のシャープで力強いフォントで時刻を表示します。
  - **12H/24H 切替**: 時計下部の「`24H` / `12H`」ボタンから、12時間表示（AM/PM付き）と24時間表示をワンクリックで切り替えることができます。
  - **秒表示のON/OFF**: 時計下部の「`秒表示: ON / OFF`」ボタンから、秒表示の有効・無効を切り替えることができます。
  - **ダークモード / ライトモード切替**: 時計下部の太陽・月アイコンボタンから、テーマ配色を瞬時に切り替えられます。
- **アナログ時計**: 秒針が滑らかにスイープ運針するミニマルな時計です。

### 3.2 カレンダー表示
- **月間表示**: 常に6週間分（42日間）の枠組みで表示され、曜日の配置やカレンダーの高さが毎月変動しないため、視覚的なブレがありません。祝日は赤色で表示され、マウスをホバーすると祝日名がツールチップで表示されます。「今月」ボタンで現在の月へ即座に戻ることができます。
- **年間表示**: カレンダー上部の「**今年**」ボタンをクリックすると、画面いっぱいに年間カレンダーモーダルが展開されます。前後の年への切り替えにも対応しています。

## 4. 祝日設定マネージャーの使い方

カレンダー上部の「**祝日設定**」ボタンをクリックすると、日本の祝日を独自にカスタマイズ・編集できる「祝日設定マネージャー」画面が開きます。

### 4.1 祝日のビジュアル編集と生データ編集
- **祝日の追加（「祝日の編集」タブ）**:  
  画面右側の入力フォームより、「日付（MM-DD形式、例: `07-07`）」と「祝日の名前」を入力して「リストに追加」ボタンを押すと、一覧にカスタム祝日が一時追加されます。
- **祝日の削除**:  
  固定祝日一覧リストの各行の右側にある「ゴミ箱」アイコンをクリックすることで、祝日を一覧から削除できます。
- **設定生データ（「設定生データ」タブ）**:  
  JSON形式の設定データを直接テキスト編集できます。保存時およびタブ切替時に構文・データ型の自動検証が行われます。

### 4.2 変更差分 (Diff) と統計情報
- **変更差分（「変更差分 (Diff)」タブ）**: アプリに組み込まれている「内蔵デフォルトの祝日設定」と、カスタマイズした「現在の設定」との行単位の差分（LCSアルゴリズムによる計算）がカラーハイライトで視覚的に表示されます。
  - **緑色のハイライト（+）**: 新しく追加された行です。
  - **赤色のハイライト（-）**: デフォルトから削除された行です。
- **設定統計情報**: 左側サイドバーには、「の日」「天皇誕生日」などのキーワードの出現定義数が自動集計して表示されます。

### 4.3 保存・適用と初期化
- **保存して適用**: 編集した祝日データを反映させるには、画面右上の「**保存して適用**」ボタンを押します。データは OS のユーザーローカルデータ領域（`%LOCALAPPDATA%/com.clondar.pro/holidays.json`）へ厳格な検証を経て安全に保存され、カレンダー画面に即時反映されます。
- **初期化**: 画面右上の「**初期化**」ボタンを押すと、いつでも内蔵の初期デフォルト設定へ安全に復元（リセット）できます。

## 5. システムトレイメニューの利用

Clondar Pro は、起動するとタスクバーの右端（システムトレイ）に常駐します。トレイ内の Clondar アイコンを**右クリック**すると、以下の機能にアクセスできます。

- **表示 / 非表示**: 非表示にしたウィジェットを再表示したり、逆に画面から一時的に消したりします。
- **最前面表示の切替**: タイトルバーのピンアイコンと同様に、常に一番手前に表示するかどうかを切り替えます（ウィンドウ側のピンアイコンの状態とも即時連動します）。
- **位置をリセット**: ディスプレイの接続変更や解像度の変更によってウィジェットが画面外に隠れて見えなくなってしまった場合、この項目を選択すると、ウィジェットが即座にメインディスプレイの中央に引き戻されます。
- **終了**: アプリケーションを完全に終了し、常駐を解除します。
