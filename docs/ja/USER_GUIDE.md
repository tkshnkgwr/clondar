# Clondar Pro ユーザーガイド (操作マニュアル)

[English Version](../en/USER_GUIDE.md) | **日本語版**

Clondar Pro をお使いいただきありがとうございます。  
このガイドでは、アプリケーションのインストールから基本操作、時計・カレンダーのカスタマイズ、「祝日設定マネージャー」の使い方まで詳しく解説します。

---

## 1. インストールと起動

### 1.1 動作環境
- **対応OS**: Windows 10 / 11 (64bit)
- **依存ランタイム**: 不要（Pure Rust ネイティブ実行ファイルのため、WebView2 等の追加ランタイムなしで単体起動します）

### 1.2 インストール手順
1. リリースパッケージ（`Clondar_Pro_2.0.0_x64-setup.exe`）をダブルクリックして実行します。
2. 言語選択画面（日本語 / English）が表示されたら、使用する言語を選択します。
3. インストーラーの指示に従ってセットアップを完了します（既定のインストール先: `%LOCALAPPDATA%\Clondar Pro\Clondar.exe`）。
4. スタートメニュー（またはインストール先フォルダ）から **Clondar Pro** を起動します。

*(※ポータブル版の `Clondar.exe` 単体でもそのまま配置・起動できます。)*

## 2. 画面構成と基本操作

Clondar Pro はデスクトップ上に美しく溶け込むウィジェットとして動作します。

- **ドラッグによる移動**:  
  タイトルバーおよび背景余白のどこでもドラッグして、画面上の好きな位置に配置できます。移動後の座標は自動保存され、次回起動時に復元されます。
- **最前面表示（ピン留め）**:  
  タイトルバー右上のピンアイコンをクリックすると、他のウィンドウの背後に隠れないよう最前面に固定されます（再度クリックで解除）。
- **背景透過の切り替え**:  
  タイトルバーまたは下部コントロールの太陽アイコンをクリックすると、背景の透過モードを切り替えることができます。
- **ヘルプ＆アプリ情報**:  
  タイトルバーの「?」アイコンをクリックすると、アプリ概要・現在のバージョン・主要機能ガイドを一覧できるモーダルが開きます。
- **トレイへの格納（非表示）**:  
  タイトルバーの「✕」ボタンをクリックするか、キーボードの `Esc` キーを押すと画面が閉じます（※モーダル表示中は先にモーダルが閉じます）。アプリ自体は終了せずシステムトレイに常駐するため、いつでも再表示できます。

## 3. 時計・カレンダーのカスタマイズ

### 3.1 時計モードの切り替え
時計上部のタブ（`DIGITAL` / `ANALOG`）をクリックして表示を切り替えます。
- **デジタル時計**: 太字の視認性の高い書体と等幅数字により、時刻更新による桁ズレのない安定した表示を行います。
  - **12H / 24H 切り替え**: 時計下部の「`24H` / `12H`」ボタンをクリックすると、24時間表記と12時間表記（AM/PM表示付き）を切り替えます。
  - **秒表示 ON/OFF**: 「`秒表示: ON / OFF`」ボタンをクリックすると秒数の表示/非表示を切り替えられます。
  - **ライト / ダークモード**: 時計下部のテーマアイコンをクリックすると、文字色や背景トーンをダーク/ライトに即座に切り替えられます。
- **アナログ時計**: 滑らかなスイープ秒針を備えたシンプルな針時計を表示します（アナログ表示中、`24H` ボタンは操作不可となります）。

### 3.2 カレンダー操作
- **月間表示**: 月の日数に関わらず常に安定した **6週間（42日分）固定レイアウト** で表示されます。日本の祝日は赤色で表示され、マウスオーバーすると祝日名がツールチップで表示されます。「**今月**」ボタンでいつでも現在の年月へ戻せます。
- **年間カレンダー**: カレンダーヘッダーの「**今年**」ボタンをクリックすると、1年分（1月〜12月）を一覧できるオーバーレイ表示が開きます。左右の矢印で前年・翌年へ切り替えられます。

## 4. 祝日設定マネージャーの使い方

カレンダー右上の「**祝日設定**」ボタンをクリックすると、祝日設定マネージャーが開きます。

### 4.1 祝日の追加・削除と生データ編集
- **祝日データの追加（「祝日の編集」タブ）**:  
  右側のフォームに日付（`MM-DD` 形式。例: `07-07`）と祝日名を入力し、「リストに追加」を押して追加できます。
- **既存祝日の削除**:  
  固定祝日一覧の各行にある削除アイコンをクリックすると、その項目を削除できます。
- **設定生データの編集（「設定生データ (JSON)」タブ）**:  
  ハッピーマンデーや年ごとの特例等を含む JSON 生データを直接編集できます。切替・保存時に自動で構文および範囲チェックが行われます。

### 4.2 変更差分 (Diff) と統計情報の確認
- **変更差分（Diff）**: 「変更差分 (Diff)」タブを開くと、標準設定との変更箇所（追加行＝緑色、削除行＝赤色）を視覚的に比較できます。
- **設定統計情報**: 設定ファイル内の主要キーワード（「の日」「天皇誕生日」「振替休日」「国民の休日」等）の登録件数が集計表示されます。

### 4.3 設定の保存と初期化
- **保存して適用**: 画面上部の「**保存して適用**」ボタンを押すと、`%LOCALAPPDATA%\com.clondar.pro\holidays.json` へ保存され、即座にカレンダーへ反映されます。
- **初期化**: 画面上部の「**初期化**」ボタンを押すと、標準の祝日設定状態にいつでも安全にリセットできます。

## 5. システムトレイ操作

タスクバー右下のシステムトレイアイコンを**右クリック**すると、以下の操作メニューを利用できます：

- **表示 / 非表示**: ウィジェットの表示状態を切り替えます。
- **最前面表示の切替**: ウィンドウのピン留め状態をトレイから操作します。
- **位置をリセット**: マルチモニターの解除や画面解像度の変更でウィンドウが画面外に見えなくなった場合、画面中央付近へ強制復帰させます。
- **終了**: Clondar Pro を完全に終了し、トレイから解除します。
